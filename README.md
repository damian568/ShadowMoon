# 🌙 ShadowMoon

An ad-free manga, manhwa and manhua reader for iPhone, built with **React Native + Expo (TypeScript)**. Titles and chapters come from the free [MangaDex API](https://api.mangadex.org/docs/).

## Features

- **Discover**: Popular Manhwa, Popular Manga, Freshly Updated, Top Rated, Popular Manhua and a *Continue Reading* row.
- **Search**: by title, with filters for Manga / Manhwa / Manhua and sorting by Popular / Updated / Top rated / New. Results load as you scroll.
- **Library lists**: ♥ **Favourite**, 📖 **Reading**, ✅ **Read**, 🔖 **For later**. Favourite is a separate flag, so a title can be a favourite *and* in a list.
- **Progress %**: every title shows the percentage of all chapters you've read (e.g. `42% · 63/150`). The Library also shows your overall percentage and chapters read.
- **Updates from the API**: new chapters are checked automatically when the app opens or comes back to the foreground (interval is configurable). New chapters show as badges and on the **Updates** tab. Pull down to check manually.
- **Reader**:
  - Vertical scroll (webtoon style) for manhwa/manhua, and right-to-left paging with pinch-to-zoom for manga. Switch modes at any time.
  - A chapter is marked read automatically when you reach its last page.
  - Prev/Next chapter buttons.
  - Data-saver mode.
- **Chapter list**: tap ◯ to mark read or unread. Long-press for *mark all previous as read*.
- **Official-only titles**: some popular titles are licensed, so MangaDex links them to the publisher's site. Those chapters open in an in-app browser, and you can still track progress on them.
- **Private**: no ads, no account, no tracking. Your library is stored only on your phone.

## Tech stack

| Part | Choice |
|---|---|
| Language | TypeScript |
| App framework | React Native 0.88 + Expo SDK 58 |
| Navigation | Expo Router (file-based, `src/app/`) |
| Backend / data | MangaDex public REST API for titles, chapters and pages (no server of our own needed) |
| Extra scores | AniList GraphQL API: community score shown on each title page (tap it to open AniList) |
| Storage | AsyncStorage (on-device) |
| Images | expo-image (memory + disk cache) |

```
src/
  providers/types.ts      The Provider contract + shared types
  providers/mangadex.ts   MangaDex provider (search, details, chapters, pages, throttling)
  providers/index.ts      Provider registry, id routing and caches (the only API screens use)
  api/anilist.ts          AniList community scores
  store/reducer.ts    Library state logic (lists, progress, updates)
  store/library.tsx   React context + persistence
  store/updates.tsx   Automatic new-chapter checker
  app/(tabs)/         Discover, Search, Library, Updates, Settings
  app/manga/[id].tsx  Title details + chapter list
  app/reader/[chapterId].tsx  Reader
assets/               App icon, splash, Android icons (generated by tools/make-icons.mjs)
```

## Adding a provider (content source)

Every source is a small plug-in in `src/providers/`. The screens never talk to MangaDex directly; they go through `src/providers/index.ts`, so a new source needs no screen changes.

1. Create `src/providers/mysource.ts` that exports an object implementing `Provider` (see `src/providers/types.ts`):
   - `search`, `getManga`, `getChapters` and `getChapterPages` are required.
   - `getMangaByIds` (batch lookup for update checks) and `getStats` are optional.
   - `types` and `sorts` say which filters your source supports; the UI hides the rest.
   - Providers use their **own raw ids**; the registry adds a `mysource:` prefix automatically.
2. Register it once, in `src/providers/index.ts`: `registerProvider(mysourceProvider)` (or push it into the `providers` array).
3. Once there are two or more providers, a **Source** picker appears in Settings. Your library keeps titles from every source.
4. Check it with `npx --yes tsx tools/test-providers.mts` (uses fake providers, plus one live MangaDex call). Copy its fake provider as a starting point for your own checks.

Only add sources that have a documented API and allow apps to use it. Known limits: pages are loaded without custom request headers, so sources that require a `Referer` header for images need small reader changes first.

## Run it on your iPhone

You need [Node.js](https://nodejs.org) (24 LTS recommended), then in this folder:

```bash
npm install
```

### Option A: instant and free, with Expo Go (good for trying it out)

1. Install **Expo Go** from the App Store on your iPhone.
2. On your PC, run `npx expo start`.
3. Scan the QR code with the iPhone Camera app. ShadowMoon opens inside Expo Go.
   - Your PC and iPhone must be on the same Wi-Fi. If the connection fails, use `npx expo start --tunnel`.

Expo Go is a "container" app, so this way ShadowMoon doesn't get its own icon on the home screen.

### Option B: a real installed app with the ShadowMoon icon (no Mac needed)

Apple only lets you install your own apps if they are signed with an **Apple Developer account** ($99/year). Expo builds the app in the cloud, so you don't need a Mac:

```bash
npm install -g eas-cli
eas login                      # free Expo account
eas device:create              # register your iPhone (open the link on the phone)
eas build -p ios --profile preview
```

When the build finishes, open the link or QR code on your iPhone and tap **Install**. On iOS 16+ you need to enable **Settings → Privacy & Security → Developer Mode** once.

Alternatively, run `eas build -p ios --profile production` then `eas submit -p ios` to send the build to **TestFlight** and install it from there.

## Notes

- MangaDex is run by volunteers. The app keeps requests under its rate limit (~5/s). Please support the scanlation groups and official releases.
- The chapter language can be changed in **Settings** (English by default).
- To regenerate the icons: `npm i --no-save sharp && node tools/make-icons.mjs assets`.
